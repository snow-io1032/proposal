エグゼクティブサマリー

前年比+5%はノルマではなく目安です。前回提案の方針どおり「お客様の満足」と「スタッフの作業環境」を良くした結果として売上を伸ばし、その進み具合を毎日・毎月の前年比で全員が感じられる仕組みを作ります。地域平均（北海道・東北の既存店 +1.9%）を3ポイント上回る水準で、施策の実行率75%なら届く設計にしています。

考え方の流れ：手間が減る → 時間が生まれる → お客様の満足が高まる → 売上が伸びる。現場が直接追うのは前の3つで、売上は結果として確認します。第1弾のデリカ部門の原価・発注の自動化はすでに試作が稼働しており、この流れの起点です。

  • 土台はデータ：POSの毎時の時報は各部署マネージャーに届いているが、店全体で集約・分析されていない。まず日報・月報を自動化し、前年同曜日比を全員が毎日見る状態を作る。
  • 前年比を色で知らせる：前年割れ（赤）／前年超え（黄）／地域平均+1.9%以上（緑）／+5%ペース（青）。色は気づきのためで、個人や部門の評価・ノルマには使わない。値上げの影響を除いた見方（買上点数）と粗利も並べる。人口から逆算する市場規模は、シェアの妥当性を確認する補助線として使う。
  • ネットスーパーは採算ラインを月報に載せる：月額200万円の固定費を回収するには、仮定次第で月商およそ1,200万〜2,200万円が必要。交渉後150万円、自社化30万円の場合も並べて経営判断の材料にする。
  • DXは売上→コスト→発信の順：AI・自動化は①売上増、②コスト削減に効くものから優先し、③食品ロスや先進的な取り組みをSNSで発信して採用につなげる。
  • ダッシュボード1枚で全部が見える：売上の前年比、現場の負担と満足、ネットスーパー採算、自動化の費用対効果、開発の進捗を同じ画面で追う。

+5%目標の意味と現状認識

+5%は地域平均の約2.6倍の伸びで、しかも人口が毎年約1%減る中での数字です。市場が縮む分を取り返したうえで、他店からシェアを取る必要があります。

指標 数値 意味
スーパー既存店 前年比（全国、2025年） +2.8% 業界全体の平均点
スーパー既存店 前年比（北海道・東北、2025年） +1.9% この地域の平均点＝合格ライン
食料支出 実質前年比（全国、2025年） −1.2% 名目は+5.5%。伸びの大半は値上げ分
中標津町の人口（住民基本台帳） 2021年 23,216人 → 2025年 22,067人 年約1%の減少
根室管内の近隣町人口（2025年1月） 別海13,964人・標津4,798人・羅臼4,267人 広域の商圏

読み方の注意：業界の伸びは主に値上げによる名目の伸びです。物価の上昇が止まれば「平均点」も下がります。実際、2026年1月の北海道・東北の既存店は前年比−0.2%でした。+5%は、値上げの追い風が弱まっても施策で届く設計にする必要があります。

強み：中標津は根室管内の買い物拠点で、近隣町の住民が集まる地域です。週末型の大型店とゲームセンターは、この「広域の目的地」としての役割と相性が良い資産です。

合格ライン（年・月・日）の考え方

合格ラインは「人口から逆算した金額」ではなく「前年の同じ曜日・同じ月の実績×係数」で引きます。人口と競合から出す市場規模は誤差が大きく、毎日の判定には使えないためです。市場規模は、シェアが現実的かを確かめる補助線にします。

判定の4段階（毎日・毎月・年間で同じ物差し）

判定 前年比 意味
赤（要対策） 100%未満 前年割れ。翌日の朝礼で原因を確認
黄（合格） 100%〜101.9% 前年は超えたが地域平均以下
緑（合格） 101.9%〜105% 地域平均（+1.9%）以上
青（目標達成） 105%以上 +5%目標の達成ペース

色の使い方：色は「どこを見に行くか」の気づきのための信号で、個人や部門の評価・ノルマには使いません。数字合わせの値引きや押し込み、報告作業の増加を防ぐためです。赤が出たら責めるのではなく、欠品や品出しの遅れなど売場の原因を一緒に探します。

値上げを除いた見方：売上の前年比は値上げだけでも上がります。実態を見るため、買上点数の前年比と粗利を必ず並べて表示します。

  • 日：前年の同じ曜日と比べる（例：今年の第3土曜日は前年の第3土曜日と）。日付で比べると曜日のずれで最大2割近くぶれるため。
  • 月：前年同月比に加え、累計（年度初めから）の前年比を並べる。1日の赤は気にせず、累計の色で判断する。
  • 年：月次の累計が105%ペースか。雪や連休の暦の差は注記で残す。
  • 部署別：同じ物差しを部署ごとに当てる。どの部署が全体の足を引っ張っているかが一目でわかる。

補助線：商圏の市場規模からの確認

家計調査（全国・二人以上世帯）の食料費から1人あたりの内食・中食の支出を月約2.6万円と置くと、商圏の食品市場は次の規模です。

範囲 実効人口 食品市場（年）
中標津町内のみ 22,067人 約68億円
広域商圏（近隣町の一部を含む） 約29,500人 約92億円

クライアント企業の食品売上をこの92億円で割った値が推定シェアです。例えばシェア35%なら年32億円、月2.7億円、1日あたり約880万円が「市場から見て妥当な水準」です。実際の売上がこれを大きく上回る場合は商圏がもっと広い、下回る場合は伸びしろがあると読みます。

※仮定：1世帯人員2.88人、外食比率17%、近隣町からの来店カバー率（別海30%・標津40%・羅臼30%）。会員データで町別の来店比率が取れれば、この仮定を実数に置き換えます。

ネットスーパー採算ライン

月額200万円の固定費を回収するには、変動費率12%の想定で月商約1,540万円（1日約85件）が必要です。店頭で買っていた客が移っただけの注文が3割あると、必要月商は約2,200万円に上がります。

損益分岐の月商は次の式で出します。

損益分岐月商 ＝ 月額システム費 ÷（粗利率 − 変動費率）
システム費（月） 変動費8% 変動費12% 変動費16% 12%・共食い3割 必要件数/日（12%）
現行 200万円 1,176万円 1,538万円 2,222万円 2,198万円 約85件
交渉後 150万円 882万円 1,154万円 1,667万円 1,648万円 約64件
自社化 30万円 176万円 231万円 333万円 330万円 約13件

※仮定：粗利率25%、客単価6,000円、変動費＝ピッキング人件費・配送・資材・決済手数料。配送料収入があれば変動費から差し引く。

月報への載せ方：毎月「ネットスーパー月商」と「損益分岐ライン」を同じグラフに描き、差額（赤字額）を経営陣とエリアマネージャーが毎月確認します。サンシとの交渉材料にもなり、自社化（月30万円）を検討する根拠にもなります。

確認が必要な実数：現在の月商と注文件数、ピッキングと配送にかかる人時、配送料収入、店頭からの移行比率（会員IDで店頭とネットの両方で買う客を見れば推定できる）。

+5%の施策ポートフォリオ

7つの施策で計画上+4.0ポイントを積み、実行率75%（+3.0pt）と地域平均+1.9%で+4.9%、ほぼ+5%に届く設計です。地域平均が0%に落ちた場合でも+3.0%は残ります。

施策 効く指標 毎日見るKPI 主な担当
近隣町からの週末広域集客（冬季の屋内レジャー） 客数 週末客数、町別来店比率 店長・イベント担当
部門別の日次PDCA（欠品・売り逃し削減） 客単価・客数 部門別前年同曜日比、時間帯別売上 各部門マネージャー
インスタ購買クラブ（季節予約、店頭受取） 客数・客単価 予約件数、受取時の追加購入額 デジタル担当・バイヤー
牛乳・卵を起点にした関連陳列 客単価 併買率、対象商品の販売数 日配・グロサリー
ネットスーパー強化（近隣町・高齢者・荒天時） 客数 注文件数、新規会員数 ネットスーパー担当
週末の購入額連動チケット 客単価 週末の客単価、発券枚数 レジ・アミューズメント
QR付き動画POP 客単価 QR読取数、対象商品の販売数 各部門＋デジタル担当

新しく加えた柱「部門別の日次PDCA」：毎時の時報を集約し、前年同曜日比と時間帯別売上を毎朝マネージャーに届けます。夕方の欠品や、売れる時間帯の品出し遅れが数字で見えれば、追加の投資なしで売り逃しを減らせます。他の施策の効果測定もこの仕組みに乗ります。

土台になる第1弾「デリカの原価・発注の自動化」：前回提案で着手し、試作が稼働中です（値上げ入力、製造数と在庫からの発注計算、原価率の一覧）。売上の寄与には数えず、作業時間の削減と粗利の改善として測ります。ここで浮いた時間を売場と接客に回すことが、上の施策を現場が無理なく続けられる前提になります。

経営ダッシュボード設計

POSの毎時の時報を自動で集約し、1つのダッシュボードと自動作成の日報・月報に流します。今は時報が各部署に届くだけで、店全体の数字を一枚で見る仕組みがありません。

画面 誰が見る 主な表示 更新
1. 経営サマリー 経営陣・金庫 日・月・年の売上前年比と色、買上点数の前年比（値上げを除いた見方）、粗利、+5%の進み具合 毎時
2. 部門別 エリアマネージャー 部門×時間帯の前年同曜日比、客数×客単価の分解、欠品の発生状況 毎時
3. ネットスーパー採算 経営陣 月商と損益分岐ライン、注文件数、赤字額の推移、交渉後・自社化の試算 日次
4. 現場の負担とDX効果 経営陣・金庫 業務ごとの作業時間と入力の手間、自動化による削減時間×時給、開発費と回収月数、開発の進捗 月次
5. お客様・ロス・採用 経営陣・広報 お客様の声、現場の声、食品ロス率、フォロワー数、求人の応募数 週次

日報・月報は「人が作る」から「AIが下書きする」へ：数字の集計と前年比の計算は自動化し、AIが「本日は青果が前年同曜日比−6%、16時以降の売上が落ちている」といった所見を下書きします。マネージャーは確認して一言加えるだけにします。

最初の一歩：時報の実物（形式・送信方法）と、今の日報・月報の作成にかかっている時間を確認します。この時間が、自動化の効果を測る基準値になります。

DX開発ロードマップと費用対効果

開発は「売上を見える化する仕組み」から始め、効果が数字で確認できたものから次に進みます。進行中のWebアプリ・サイト構築とHACCP対応も、この全体計画の中に位置づけます。

費用対効果の測り方

自動化の効果は、削減できた作業時間を金額に換算して開発費と比べます。

月間効果 ＝ 削減時間（時間/月）× 時給 ＋ ロス削減額 ＋ 売上増による粗利増

例えば、10部門それぞれ30分かかっている日報作成がほぼなくなると、1日約5時間、時給1,300円なら月約19.5万円分の時間が売場に戻ります（時給と作業時間は仮定。Phase 0で実測します）。

先行事例（公表数値）

企業 取り組み 公表された効果
ヤオコー 需要予測型の自動発注（日立） 実証店の発注時間を3時間から25分に短縮
バロー（中部フーズ） 惣菜のAI自動発注 事前検証で利益約5%増、発注作業時間27%減
バロー（日本気象協会・ソフトバンク） 気象・人流データによるAI値引き 惣菜の廃棄量約13%減、作業時間約37%短縮

いずれも大手の事例ですが、仕組みの中身（前年比の自動集計、需要予測、値引きの最適化）は単店でも小さく始められます。

発信・採用戦略

取り組みそのものを発信し、「田舎でも先進的な職場」として採用につなげます。町は若者、特に若い女性の町外流出を人口減少の主な要因に挙げており、魅力ある職場づくりは町の課題とも重なります。

発信テーマ 中身の例 つながる成果
食品ロス削減 毎月のロス削減量を公開、見切り品の告知 ロス率の低下、来店動機
データで動く売場 部門が前年比を見て売場を変えた事例 社員の誇り、現場の参加
こだわり素材の裏側 各部門のリール動画（QR動画POPと共用） 客単価、高価格の納得感
地域の先進事例 AI・自動化の導入と効果を数字で紹介 採用の応募、取材、取引先の信頼

優先順位は変えない：AIで効率化ツールを作ること自体は目的にしません。判断の順番は①売上増、②コスト削減、③発信と採用です。発信は①②の成果を伝える手段として位置づけます。

採用KPI：求人への応募数と、応募者が「SNSや取り組みを見て」と答えた割合を、ダッシュボードの画面5で追います。

リスクと前提

最大のリスクは、値上げの追い風が止まって地域平均が0%付近に落ちることです。その場合、施策の実行率75%でも+3.0%にとどまり、+5%には施策の上積み（計画で+5ポイント規模）が必要になります。

リスク 影響 対応
+5%や色判定がノルマとして伝わる 値引き・押し込みの数字合わせ、報告の増加 「目安」と明言し、評価には使わない。赤は原因探しの合図として扱う
物価上昇の鈍化 地域平均の+1.9%が消える 月次で地域平均を更新し、買上点数の前年比で実態を見る
時報の形式が自動取込に向かない ダッシュボードが遅れる Phase 0で実物を確認。紙・PDFなら読取の工程を足す
入力が増えて現場負担が増す 続かなくなる 入力は最小限。自動化で浮いた時間の範囲で施策を足す
台帳にない材料の価格更新が止まる 原価率が実態とずれる 手入力の担当と頻度を決める
現場が数字を見ない 日次の振り返りが回らない 画面は色と一言の所見に絞り、朝礼で1分確認
購入額連動チケット 景品表示法・ゲームセンターの規制 景品の上限（取引額の20%）と運営主体を確認してから実施
ネットスーパーの共食い 採算ラインが上がる 会員IDで店頭からの移行比率を測る
個人情報の扱い 会員データの目的外利用 町名・年代など集計単位で扱い、利用目的を明示

この資料の数値の前提：市場規模、採算ライン、施策の寄与はすべて仮定にもとづく試算です。前年の部門別・曜日別の実績、ネットスーパーの月商、会員データを受け取りしだい置き換えます。

金庫役員との相談論点

相談で決めたいのは、金庫がこの取り組みにどう関わるか（資金・伴走・横展開）の3点です。前提として「+5%は目安でノルマにしない」という前回提案の方針を、金庫側とも共有します。

  1. 伴走の形：金庫の取引先支援として位置づけるか。月次のダッシュボード（画面1と4）を金庫とも共有し、成果を一緒に確認する形が取れるか。
  2. 資金：ダッシュボード開発、将来のネットスーパー自社化（月30万円水準）への投資に、融資や国のIT・AI導入系の補助金をどう組み合わせるか。補助金は年度ごとに名称・要件が変わるため、公募時点で確認する。
  3. 成果の物差し：金庫として見たい指標は何か。案は「売上と買上点数の前年比」「現場の作業時間の削減（DX投資の回収月数）」「ネットスーパーの月次赤字額」の3つ。
  4. 横展開：この仕組み（時報の自動集約、前年比の色判定、採算ライン）を、管内の他の小売・飲食の取引先にも展開できるか。
  5. 情報の取り扱い：クライアント企業の売上・会員データを金庫と共有する範囲と、守秘のルール。
  • 金庫としての関与の形を決める
  • 共有するダッシュボード画面と頻度を決める
  • 資金・補助金の検討担当を決める
