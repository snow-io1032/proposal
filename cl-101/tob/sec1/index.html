【予算ゼロ円プラン】Windows標準機能の最大活用と社内運用の統制案

💰 対策費用：初期費用 0円 / 月額費用 0円（完全無料）

外部の有料セキュリティ製品を導入せず、現有リソース（Windowsの標準機能）の徹底的な最適化と、全社的な運用ルールの厳格化によって、最低限必要な防御力を自社で構築するプランです。本日より即時実施が可能です。

1. サーバーPC（共有PC）の要塞化（今すぐ実施する技術対策）

社内サーバーとして使用している一般PCについて、設定を以下のように変更・固定します。

① サーバーPCでのWeb閲覧・メール利用の「絶対禁止」

サイバーウイルスの侵入経路の9割は「不審なWebサイト」か「メールの添付ファイル」です。サーバーPCはファイル共有の機能だけに徹し、人間が直接操作してインターネットサーフィンやメールチェックを行う行為を禁止します。

② 接続中バックアップの廃止と「手動オフライン管理」

ランサムウェア（身代金要求ウイルス）に感染すると、PCに繋がっている外付けHDDも同時にすべて暗号化（破壊）されます。外付けHDDを2台用意し、日替わりでバックアップを取得。バックアップ終了後は必ず物理的にケーブルを抜いて隔離保管します。

③ Windows UpdateおよびDefenderの強制自動更新

Windows標準の「Windows Defender」は、OSが最新状態に保たれて初めて本来の防御力を発揮します。自動更新スケジュールを毎週末に強制設定し、アップデートの未適用状態を無くします。

2. 社内運用ルールの統一と統制（人的対策）

セキュリティソフトを購入しない代わりに、社員一人ひとりの運用の厳格化でカバーします。

  • 「個人持ち込みセキュリティソフト」の利用禁止
    現在、善意で個人のソフトを入れている社員がいますが、Windows Defenderと競合して動作異常を起こしたり、保護がすり抜ける原因になります。全社で「Windows Defenderのみ」に統一します。
  • パスワードの総見直し（使い回し・初期設定の禁止）
    共有ファイルへのアクセスパスワードやPCログインパスワードについて、推測されやすい単純なもの（例: 1234、password、会社名など）を禁止し、英数字・記号を組み合わせた12桁以上に変更を義務付けます。

3. 自社運用プラン（無料）における限界と懸念点

本プランは費用がかからない反面、以下の重大なデメリット・運用負荷が残ることを予め留意する必要があります。

⚠️ 自社運用の限界とリスク
  1. ウイルス検知後の「対処」はすべて手探り： Windows Defenderはウイルスを検知・隔離するだけです。ネットワーク内のどこまで感染が広がったかの調査や、感染端末の安全な復旧は自力で行う必要があり、長期間の業務停止に陥るリスクがあります。
  2. 人的ミスによる破綻： 「バックアップのケーブルを抜き忘れた日に感染する」「社員が不審なメールを開いてしまう」といった1つの人間ミスで、全社データが損失する脆さがあります。
  3. サイバー事故時の全額自己負担： 万が一、取引先（大手スーパー様）へ被害を及ぼして損害賠償を求められた場合、あるいはシステム復旧に専門業者を呼ぶ場合、すべての費用（数百万円〜）が会社の自己負担となります。

4. 結論とおすすめの進め方

まずは「費用0円」でできる本プランのルール作り（サーバーPCでのネット禁止、バックアップの物理隔離）を本日より即座にスタートさせます。

その運用を行いながら、やはり毎日の手動バックアップの手間や、万が一の損害賠償リスク（保険の有無）が経営上の懸念として残る場合は、先に提案いたしました「国の補助金を活用した月額実質600円の外部委託プラン」への切り替えを再検討することを推奨いたします。
