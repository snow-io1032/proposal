エグゼクティブサマリー

目標は「1年目に赤字を半分に、2年目に黒字化」です。直近期は売上51億円（前年比−3.8%）、当期純利益−5,000万円の2期連続赤字ですが、赤字は前年より2,200万円縮んでいます。費用の削減はすでにかなり進んでいるため、これからの主役は売上の回復です。前年比+5%は、この2年計画が軌道に乗った後の中期の目安とし、ノルマにはしません。

考え方の流れ：手間が減る → 時間が生まれる → お客様の満足が高まる → 売上が伸びる。現場が直接追うのは前の3つで、売上は結果として確認します。第1弾のデリカ部門の原価・発注の自動化はすでに試作が稼働しており、この流れの起点です。

  • 売上+1%で利益は約1,275万円戻る：粗利率25%と置くと、赤字5,000万円を売上だけで埋めるには約+4%が必要。売上の回復に、ロス削減とネットスーパーの費用見直しを組み合わせる。
  • ネットスーパーの費用は赤字の約半分：システム費は年2,400万円で、純損失の48%に当たる。採算ラインを月報に載せ、交渉（月150万円）と自社化（月30万円）を判断する材料にする。
  • 最優先は売上減の原因の特定：直近期は地域平均（北海道・東北の既存店 +1.9%）を約6ポイント下回った。POSの毎時の時報を店全体で集約し、どの部門・どの時間帯・客数か客単価かを見える化する。
  • 前年比を色で知らせる：前年割れ（赤）／下げ止め（黄）／1年目目標+1%以上（緑）／2年目目標+2.5%以上（青）。色は気づきのためで、評価・ノルマには使わない。値上げを除いた見方（買上点数）と粗利も並べる。
  • DXは売上→コスト→発信の順：AI・自動化は①売上増、②コスト削減に効くものから優先し、③食品ロスや先進的な取り組みをSNSで発信して採用につなげる。

現状認識

直近期は売上が2億円減ったにもかかわらず、赤字は2,200万円縮みました。売上減で失った粗利（約5,000万円）を上回る、約7,000万円の費用削減を進めた計算です。

指標 前期 直近期 増減
売上 約53億円 51億円 −2億円（−3.8%）
当期純利益 −7,200万円 −5,000万円 +2,200万円
売上減で失った粗利（粗利率25%と仮定） 約−5,000万円
費用削減（差し引きの推計） 約+7,000万円

読み取れること：削れる費用はかなり削った後です。同じペースの削減を続けるのは難しく、売場の力を落とすおそれもあります。黒字化の主役は売上の回復で、費用の見直しはネットスーパーのように金額の大きいものに絞ります。

地域・業界の指標 数値 意味
スーパー既存店 前年比（全国、2025年） +2.8% 業界全体の平均点
スーパー既存店 前年比（北海道・東北、2025年） +1.9% この地域の平均点
食料支出 実質前年比（全国、2025年） −1.2% 名目は+5.5%。伸びの大半は値上げ分
中標津町の人口（住民基本台帳） 2021年 23,216人 → 2025年 22,067人 年約1%の減少
根室管内の近隣町人口（2025年1月） 別海13,964人・標津4,798人・羅臼4,267人 広域の商圏

地域との差：地域の平均が+1.9%の中で−3.8%なので、約6ポイント下回っています。人口減少（年約1%）だけでは説明できず、競合の出店や特定部門の落ち込みなど、店に固有の原因があるはずです。原因によって打つ手が変わるため、最初の3か月で特定します。

強み：中標津は根室管内の買い物拠点で、近隣町の住民が集まる地域です。週末型の大型店とゲームセンターは、この「広域の目的地」としての役割と相性が良い資産です。

2年で黒字化する計画

1年目に赤字を約1,600万円まで縮め、2年目に約2,700万円の黒字にする計画です。売上の回復、ロス・値下げの削減、ネットスーパーの費用見直し、自動化による残業削減の4つを積み上げます。

売上前年比 改善額（直近期比・累計） 当期純利益（見込み） 主な中身
1年目 +1%（下げ止め） 約+3,400万円 約−1,600万円 売上+1%の粗利 1,280万、ロス・値下げ削減 1,280万、ネットスーパー交渉 600万、残業削減 230万
2年目 +2.5% 約+7,700万円 約+2,700万円 売上の回復 3,190万、ネットスーパー自社化 2,040万、ロス・値下げ削減 2,040万、残業削減 460万

※仮定：粗利率25%、ロス・値下げ削減は売上の0.25%（1年目）・0.4%（2年目）。ネットスーパー自社化の2,040万円は月額費用の差（200万円→30万円）で、開発費と移行費は含まない。当期純利益には特別損益と税金が含まれるため、本業の進み具合は営業利益で確認する。

+5%の位置づけ：前年比+5%は、2年目以降に売上を前々期の水準（約53億円）へ戻すための中期の目安です。毎日の色判定は、1年目+1%・2年目+2.5%を基準にします。

合格ライン（年・月・日）の考え方

合格ラインは「前年の同じ曜日・同じ月の実績×係数」で引きます。人口と競合から出す市場規模は誤差が大きく、毎日の判定には使えないためです。

判定の4段階（毎日・毎月・年間で同じ物差し）

判定 前年比 意味
赤（要対策） 100%未満 前年割れ。翌日の朝礼で原因を確認
黄（下げ止め） 100%〜101% 前年は超えたが1年目目標に届かない
緑（1年目目標） 101%〜102.5% 1年目目標（+1%）以上
青（2年目目標） 102.5%以上 2年目目標（+2.5%）のペース

色の使い方：色は「どこを見に行くか」の気づきのための信号で、個人や部門の評価・ノルマには使いません。数字合わせの値引きや押し込み、報告作業の増加を防ぐためです。赤が出たら責めるのではなく、欠品や品出しの遅れなど売場の原因を一緒に探します。

値上げを除いた見方：売上の前年比は値上げだけでも上がります。実態を見るため、買上点数の前年比と粗利を必ず並べて表示します。

  • 日：前年の同じ曜日と比べる（例：今年の第3土曜日は前年の第3土曜日と）。日付で比べると曜日のずれで最大2割近くぶれるため。
  • 月：前年同月比に加え、累計（年度初めから）の前年比を並べる。1日の赤は気にせず、累計の色で判断する。
  • 年：月次の累計が目標のペースか。雪や連休の暦の差は注記で残す。
  • 部署別：同じ物差しを部署ごとに当てる。どの部署が全体の足を引っ張っているかが一目でわかる。

補助線：商圏の市場規模（要修正）

家計調査（全国・二人以上世帯）の食料費から試算した広域商圏の食品市場は約92億円です。

範囲 実効人口 食品市場（年）
中標津町内のみ 22,067人 約68億円
広域商圏（近隣町の一部を含む） 約29,500人 約92億円

ただし直近期の売上51億円はこの55%に当たり、地方の1店舗のシェアとしては高すぎます。商圏が近隣町より広いか、売上に食品以外（衣料・住居関連・テナント・ゲームセンターなど）が含まれているためと考えられます。売上の内訳を確認してから、シェアの補助線として使います。

※仮定：1人あたりの内食・中食の支出 月約2.6万円、1世帯人員2.88人、外食比率17%、近隣町からの来店カバー率（別海30%・標津40%・羅臼30%）。

ネットスーパー採算ライン

ネットスーパーのシステム費は年2,400万円で、直近期の純損失5,000万円の48%に当たります。月額200万円を回収するには、変動費率12%の想定で月商約1,540万円（1日約85件）が必要です。店頭で買っていた客が移っただけの注文が3割あると、必要月商は約2,200万円に上がります。

損益分岐の月商は次の式で出します。

システム費（月） 変動費8% 変動費12% 変動費16% 12%・共食い3割 必要件数/日（12%）
現行 200万円 1,176万円 1,538万円 2,222万円 2,198万円 約85件
交渉後 150万円 882万円 1,154万円 1,667万円 1,648万円 約64件
自社化 30万円 176万円 231万円 333万円 330万円 約13件

※仮定：粗利率25%、客単価6,000円、変動費＝ピッキング人件費・配送・資材・決済手数料。配送料収入があれば変動費から差し引く。

月報への載せ方：毎月「ネットスーパー月商」と「損益分岐ライン」を同じグラフに描き、差額（赤字額）を経営陣とエリアマネージャーが毎月確認します。1年目はサンシとの条件交渉（月150万円）の材料に、2年目は自社化（月30万円）を判断する根拠にします。

確認が必要な実数：現在の月商と注文件数、ピッキングと配送にかかる人時、配送料収入、店頭からの移行比率（会員IDで店頭とネットの両方で買う客を見れば推定できる）。

売上回復の施策

1年目+1%、2年目+2.5%の売上回復を、7つの施策で狙います。施策の計画上の積み上げは+4.0ポイントですが、直近期の−3.8%の原因が続けば効果は打ち消されます。そのため目標は控えめに置き、施策は原因が分かった部門から優先して始めます。

施策 効く指標 毎日見るKPI 主な担当

近隣町からの週末広域集客（冬季の屋内レジャー） 客数 週末客数、町別来店比率 店長・イベント担当
インスタ購買クラブ（季節予約、店頭受取） 客数・客単価 予約件数、受取時の追加購入額 デジタル担当・バイヤー

最初に始める「部門別の日次PDCA」：毎時の時報を集約し、前年同曜日比と時間帯別売上を毎朝マネージャーに届けます。売上が落ちた部門と時間帯が分かれば、原因の特定と売り逃しの削減を、追加の投資なしで同時に進められます。他の施策の効果測定もこの仕組みに乗ります。

土台になる第1弾「デリカの原価・発注の自動化」：前回のご提案で着手し、試作が稼働中です（値上げ入力、製造数と在庫からの発注計算、原価率の一覧）。売上の寄与には数えず、作業時間の削減とロス・粗利の改善として測ります。ここで浮いた時間を売場と接客に回すことが、上の施策を現場が無理なく続けられる前提になります。

経営ダッシュボード設計

POSの毎時の時報を自動で集約し、1つのダッシュボードと自動作成の日報・月報に流します。今は時報が各部署に届くだけで、店全体の数字を一枚で見る仕組みがありません。

画面 誰が見る 主な表示 更新
1. 経営サマリー 経営陣 日・月・年の売上前年比と色、買上点数の前年比（値上げを除いた見方）、粗利、黒字化計画に対する利益の進み具合 毎時（利益は月次）
2. 部門別 エリアマネージャー 部門×時間帯の前年同曜日比、客数×客単価の分解、欠品の発生状況 毎時
3. ネットスーパー採算 経営陣 月商と損益分岐ライン、注文件数、赤字額の推移、交渉後・自社化の試算 日次
4. 現場の負担とDX効果 経営陣 業務ごとの作業時間と入力の手間、自動化による削減時間×時給、開発費と回収月数、開発の進捗 月次

日報・月報は「人が作る」から「AIが下書きする」へ：数字の集計と前年比の計算は自動化し、AIが「本日は青果が前年同曜日比−6%、16時以降の売上が落ちている」といった所見を下書きします。マネージャーは確認して一言加えるだけにします。

最初の一歩：時報の実物（形式・送信方法）と、今の日報・月報の作成にかかっている時間を確認します。この時間が、自動化の効果を測る基準値になります。

DX開発ロードマップと費用対効果

開発は「売上を見える化する仕組み」から始め、効果が数字で確認できたものから次に進みます。赤字の中での投資になるため、各フェーズの終わりに効果を確かめ、費用を上回らないものは進めません。進行中のWebアプリ・サイト構築とHACCP対応も、この全体計画の中に位置づけます。

費用対効果の測り方

自動化の効果は、削減できた作業時間を金額に換算して開発費と比べます。

月間効果 ＝ 削減時間（時間/月）× 時給 ＋ ロス削減額 ＋ 売上増による粗利増

例えば、10部門それぞれ30分かかっている日報作成がほぼなくなると、1日約5時間、時給1,300円なら月約19.5万円分の時間が売場に戻ります。この時間を残業の削減に充てた分が、黒字化計画の「残業削減」になります（時給と作業時間は仮定。Phase 0で実測します）。

先行事例（公表数値）

企業 取り組み 公表された効果
ヤオコー 需要予測型の自動発注（日立） 実証店の発注時間を3時間から25分に短縮
バロー（中部フーズ） 惣菜のAI自動発注 事前検証で利益約5%増、発注作業時間27%減
バロー（日本気象協会・ソフトバンク） 気象・人流データによるAI値引き 惣菜の廃棄量約13%減、作業時間約37%短縮

いずれも大手の事例ですが、仕組みの中身（前年比の自動集計、需要予測、値引きの最適化）は単店でも小さく始められます。

発信・採用戦略

取り組みそのものを発信し、「田舎でも先進的な職場」として採用につなげます。町は若者、特に若い女性の町外流出を人口減少の主な要因に挙げており、魅力ある職場づくりは町の課題とも重なります。

発信テーマ 中身の例 つながる成果
食品ロス削減 毎月のロス削減量を公開、見切り品の告知 ロス率の低下、来店動機
データで動く売場 部門が前年比を見て売場を変えた事例 社員の誇り、現場の参加
こだわり素材の裏側 各部門のリール動画（QR動画POPと共用） 客単価、高価格の納得感
地域の先進事例 AI・自動化の導入と効果を数字で紹介 採用の応募、取材、取引先の信頼

優先順位は変えない：AIで効率化ツールを作ること自体は目的にしません。判断の順番は①売上増、②コスト削減、③発信と採用です。発信は①②の成果を伝える手段として位置づけます。

採用KPI：求人への応募数と、応募者が「SNSや取り組みを見て」と答えた割合を、ダッシュボードの画面5で追います。

リスクと前提

最大のリスクは、売上が落ちた原因が分からないまま続くことです。競合の出店のように続く原因なら、施策の効果が打ち消され、1年目の下げ止めも難しくなります。最初の3か月で原因を特定し、計画を見直します。

リスク 影響 対応
売上減の原因が続く 下げ止まらず、黒字化が遅れる 部門・時間帯・客数×客単価で原因を特定し、3か月後に計画を見直す
目標や色判定がノルマとして伝わる 値引き・押し込みの数字合わせ、報告の増加 「目安」と明言し、評価には使わない。赤は原因探しの合図として扱う

当期純利益に本業以外の損益が入る 本業の改善が見えにくい 営業利益と減価償却費で進み具合を見る
