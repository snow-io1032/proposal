# 建設業の採用ページ・モックアップ作成

企業担当者が自社の基本情報を入力すると、採用特設ページの試作をブラウザー内で作成できます。

## 使い方

1. `builder.html` をブラウザーで開きます。GitHub上でコードが表示される場合は、ファイルをダウンロードして開いてください。単一HTMLなので単独で動作します。
2. 会社名、募集職種、勤務地、仕事内容の4項目を入力し、**モックアップを作成**を押します。
3. 必要なら建設業の分野、待遇、写真、選考の流れを追記します。変更はプレビューへ反映されます。
4. **モックアップHTMLを保存**で見本ページを保存します。後日編集するときは**入力内容を保存（JSON）**でデータを保存し、作成画面で読み込みます。

「架空の入力例を試す」から、入力前に画面の完成形を確認できます。

## 取り扱い

- 入力はブラウザー内で処理し、サーバーには送信しません。文章はローカルストレージに一時保存します。
- 写真はブラウザーを閉じると選択が解除されます。JSONには含まれません。書き出したHTMLには選択中の写真、未選択ならAI生成のサンプル画像を内包します。
- モックアップには未確認の表示が付き、応募受付のリンクは有効になりません。公開用の求人ページは募集条件、権利、応募先、個人情報の扱いを別途確認して制作します。
- `index.html` は架空の完成見本です。`sample-hero.jpg` はAI生成のイメージ画像です。
